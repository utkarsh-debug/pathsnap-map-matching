## Section 4: Bayesian hyperparameter optimisation (chosen model: XGBoost)

1. **Hyperparameters in the search:** n_estimators, learning_rate, max_depth, min_child_weight, subsample, colsample_bytree, reg_lambda, reg_alpha, gamma.
2. **Ranges / distributions and why:**

| hyperparameter | range | justification recorded in `bo_search_space.json` |
|---|---|---|
| n_estimators | int [100, 600] | number of boosting rounds/trees; the untuned model uses 300, so the range brackets it from under- to over-fitted |
| learning_rate | float log-uniform [0.01, 0.3] | log scale because its effect is multiplicative; 0.05 (untuned) sits inside; small values need more trees |
| max_depth | int [3, 10] | tree depth controls interaction order; 6 (untuned) is inside; >10 overfits on ~1.9M rows of noisy labels |
| min_child_weight | float log-uniform [1, 50] | minimum hessian per leaf: larger values regularise noisy-label regions (e.g. the 2 unreliable trips) |
| subsample | float uniform [0.5, 1.0] | row subsampling per tree (decorrelates trees); below 0.5 loses too much signal |
| colsample_bytree | float uniform [0.5, 1.0] | feature subsampling per tree; useful because several of the 19 features are correlated (distance family) |
| reg_lambda | float log-uniform [0.01, 50] | L2 leaf-weight penalty, log scale; default is 1 |
| reg_alpha | float log-uniform [0.001, 10] | L1 leaf-weight penalty, log scale; small default effect, allowed to grow for sparsity |
| gamma | float uniform [0, 5] | minimum loss reduction to split; prunes splits that only fit label noise |
